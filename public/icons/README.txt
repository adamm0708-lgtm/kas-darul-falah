IKON PWA — Kas Langgar Darul Falah
===================================
4 file PNG ini adalah ikon aplikasi. Unggah ke repo GitHub
adamm0708-lgtm/kas-darul-falah, folder public/icons/ :
  - icon-192.png (192x192)
  - icon-512.png (512x512)
  - icon-maskable-512.png (512x512, maskable — ada padding aman di tengah)
  - icon-180.png (180x180, untuk iPhone / apple-touch-icon)

Cara:
1. Buka https://github.com/adamm0708-lgtm/kas-darul-falah/tree/main/public/icons
2. Klik "Add file" -> "Upload files"
3. Seret keempat file PNG ini, lalu "Commit changes".
4. Vercel akan deploy otomatis; setelah itu tombol Install di HP muncul penuh.

Catatan: file icon.svg (ikon yang sama, versi vektor) sudah ada di folder
yang sama lewat push kode — empat PNG ini melengkapinya.
